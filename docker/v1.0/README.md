# PrestServ V1.0 — Dockerfile histórico

Esta pasta é reservada para a **cópia exata do Dockerfile atualmente usado em produção**.

No servidor, o arquivo aparece como `Dockerfile` não rastreado pelo Git. Copie seu conteúdo para `docker/v1.0/Dockerfile` no repositório local e então faça commit.

Não substitua o Dockerfile histórico pelo modelo da V2: versões antigas podem usar dependências e comandos diferentes.
